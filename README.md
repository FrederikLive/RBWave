# SpectraWave (Fred's RBWave)

Rekordbox-style Multicolor Waveform for Ableton Live.

## Overview
SpectraWave is a Max for Live Audio Effect that displays an analyzed, multicolor waveform for Ableton audio clips, without altering Ableton's built-in waveform renderer.
